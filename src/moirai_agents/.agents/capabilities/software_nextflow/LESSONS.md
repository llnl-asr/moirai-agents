# Lessons: software_nextflow

- [L-0d966b81] Slurm job script pattern for Nextflow with node-local podman storage: run nextflow in the background (`nextflow ... &; NFPID=$!`), `trap 'kill -TERM $NFPID; wait $NFPID; cleanup; exit 143' TERM`, `wait $NFPID`, then cleanup (podman unshare rm -rf <graph>; rm -rf <tmp>): a plain foreground nextflow defers the bash trap until it ends, so scancel (SIGTERM) left the podman storage in /tmp. Template: runs/smoke/run_nf.sh of the taxteller session (args: samplesheet, tag; NXF_RESUME=1 adds -resume for plain runs only).

- [L-ac4d84be] taxteller needs a pinned Nextflow: 26.10.5 fails to parse nextflow.config ("`manifest` is not defined", "`validation` is not defined": the strict v2 config syntax), NXF_VER=25.04.6 (downloaded on the login node with NXF_OFFLINE=false, then NXF_OFFLINE=true in the job) parses it, and nf-schema@2.3.0 must be installed once for that NXF_HOME. The pipeline needs no changes for that. In a Slurm job, podman 4.9 ignores XDG_RUNTIME_DIR/CONTAINERS_CONF for its events dir ("creating events dirs: mkdir /run/user/<uid>: permission denied"): put a podman wrapper first on PATH that execs /usr/bin/podman --root --runroot --tmpdir <node-local> --events-backend=file --storage-opt overlay.ignore_chown_errors=true (the last one because images such as community.wave.seqera.io fastp contain files owned by uid 57439 and the user has no subuid range: "lchown /home/mambauser: invalid argument"). Nextflow tasks and the seqscreen script then use the wrapper. The package podman profile only bind-mounts /p/lustre2: add -v /p/vast1 and -v /usr/workspace in a -c overlay.

- [L-639c53db] Nextflow plugins can be installed on the login node before the compute job: with JAVA_HOME=/usr/lib/jvm/java-17-openjdk, NXF_HOME=<session>/tools/nxf_home, NXF_OFFLINE=false, run `./nextflow plugin install nf-schema@2.3.0` from <session>/tools (about seconds, lands in $NXF_HOME/plugins/nf-schema-2.3.0). Compute nodes then run with the plugin cache already in the session, so the pipeline needs no network for plugins. Check `ls $NXF_HOME/plugins` after the install.
